# DELTA-001 — Threading contract lacks live realization

Status: open

The private contrib application implements automatic, Discord-manual, and
operator thread workflows over one durable reconciliation path. Its
credential-free policy, race, crash, adapter, runtime, and composed E2E evidence
is recorded in
[experiment 0010](../../.experiments/0010-implemented-tracer-bullet.md).

No declared runtime has exercised those paths against an isolated live Discord
target. The previous implementation lives in a separate historical repository
and its former production process cannot be found. It is reference evidence,
not a realization of this contract.

Local composition does not prove interaction registration, effective live
permissions, a real Gateway-to-REST thread mutation, artifact cleanup, or a
deployment handoff. Those verdict-bearing lanes remain `UNRUN`.

Close condition: a dedicated staging E2E receipt proves automatic, **Create
Thread**, and operator-retroactive paths against the exact packaged release,
including repeat `AlreadySatisfied`, Discord-authoritative permission denial,
owned artifact cleanup, and the parent operations readiness checks.
