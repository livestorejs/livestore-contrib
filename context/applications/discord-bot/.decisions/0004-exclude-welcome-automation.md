# 0004 - Keep welcome automation out of initial scope

Status: accepted

## Context

The merged old bot establishes the initial feature families. Member-welcome
automation exists only on an unmerged divergent branch and has no accepted
contract or rollout evidence.

## Decision

Keep welcome automation roadmap-only. It is not initial feature parity and may
return as a separate proposal with its own policy, privacy, and rollout review.

Accepted 2026-08-23 as a scope-preserving technical default.
