# 0001 - Start `/docs` with an explicit query and no ambient context

Status: accepted

## Context

Implicit thread or channel history would expand the privacy and disclosure
boundary beyond an explicit documentation request. The initial command can be
useful without contextual history.

## Decision

The initial `/docs` mode requires an explicit query and sends no ambient
conversation history. Contextual selection remains a future separately
disclosed and authorized capability.

Accepted 2026-08-23 as the safe initial context boundary.
