# 0002 - Render a compact mechanically derived source footer

Status: accepted

## Context

Discord answers need verifiable provenance without making every answer
unreadably verbose or requiring a claim-segmentation protocol.

## Decision

Render a compact `Sources:` footer containing unique normalized links derived
from the Documentation Snapshot. Per-claim citation rendering remains a future
experiment and is not required by the initial contract.

Accepted 2026-08-23.
